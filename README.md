# Ommi Pavan Sai — Java Backend Developer Portfolio

Professional portfolio website of **Ommi Pavan Sai**, Java Backend Developer specializing in Spring Boot, REST APIs, MySQL, Hibernate/JPA, and scalable backend workflows.

## 🚀 Tech Stack
- **Backend Core**: Java, Spring Boot, Spring Data JPA, Hibernate, REST APIs
- **Database & Storage**: MySQL, H2
- **Frontend & UI**: HTML5, Vanilla CSS3, JavaScript, Canvas Particle Engine
- **Tools**: Git, GitHub, IntelliJ IDEA, Postman

## 📁 Project Structure
- `index.html` — Clean semantic HTML portfolio markup
- `style.css` — Modern responsive styling with galaxy dark theme and glassmorphism
- `script.js` — Interactive particle canvas and mobile navigation controls
- `images/` — Portfolio assets and project previews
